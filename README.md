### 🤝 How I build
I work AI-assisted (Claude, and others) — I define the problem, design the
actual logic and formatting (table layouts, stamp placement, data models),
and use AI to help implement it, then test and iterate against real,
day-to-day use at K&K. I'm upfront about this process rather than hiding
it — it's how I went from zero software background to shipping a tool
that's now in daily production use, in a matter of months.
